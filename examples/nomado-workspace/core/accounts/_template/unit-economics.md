## Формула

```
себестоимость   = закуп + доставка_до_склада_МП + упаковка + брак
комиссия        = цена_продажи × ставка_комиссии
логистика       = логистика_прямая + логистика_обратная × (1 − процент_выкупа)
налог           = цена_продажи × ставка_налога          # УСН «доходы» — с оборота
маржа_за_шт     = цена_продажи − себестоимость − комиссия − логистика − хранение − налог
маржинальность  = маржа_за_шт ÷ цена_продажи × 100%
```

Точка безубыточности по цене:

```
цена_min = (себестоимость + логистика + хранение) ÷ (1 − ставка_комиссии − ставка_налога)
```

## Пороги решения

- маржинальность < 15% — не заходим, съест первая же волна возвратов или демпинг;
- 15–25% — только при быстрой оборачиваемости (< 45 дней) и малой партии на тест;
- > 25% — можно на тестовую партию, если ниша не монополизирована.

Пороги — рабочая эвристика, а не закон; после первых своих продаж заменить на факт.

## Тестовая партия

```
бюджет_теста = себестоимость × партия + реклама_на_разгон
```

Не заходить в товар, где минимальная партия поставщика делает `бюджет_теста` больше,
чем не жалко потерять целиком.
