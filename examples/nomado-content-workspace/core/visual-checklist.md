# Чек-лист разбора визуала

Порядок важен: пункты идут по убыванию влияния. Первое фото решает больше,
чем всё остальное вместе.

## Первое фото

- [ ] Понятно за полсекунды, что это за товар
- [ ] Товар занимает большую часть кадра, не теряется в фоне
- [ ] Читается в размере плитки выдачи (~200 px по ширине), а не только в полном
- [ ] Не сливается с белым фоном соседних карточек — есть чем зацепиться взглядом
- [ ] Инфографика (если есть) не закрывает сам товар
- [ ] Текст на фото читается на телефоне: крупно, контрастно, коротко

## Остальные фото

- [ ] Есть масштаб — предмет рядом с рукой, лицом, привычным объектом
- [ ] Показано в использовании, а не только на белом
- [ ] Закрыты типовые вопросы из отзывов (размер, комплектация, материал)
- [ ] Последовательность осмысленная: общий вид → детали → применение

## Против конкурентов

- [ ] Карточка отличается от соседних в выдаче хоть чем-то
- [ ] Не повторяет чужую композицию буквально
- [ ] Если все в категории делают одинаково — понятно, почему мы делаем так же
      (иногда шаблон категории — это ожидание покупателя, ломать его вредно)

## Стоп-сигналы

- Фото со стока, не наш товар
- Разные оттенки одного товара на разных фото
- Инфографика мельче 24 px по высоте текста
- Больше трёх утверждений на одном кадре
